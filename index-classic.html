隐私政策

此 HTML5 测速服务器已启用遥测功能。

我们收集的数据

测试结束后，将收集并储存以下数据：

  • 测试 ID
  • 测试时间
  • 测试结果（下载与上传速度、延迟和抖动）
  • IP 地址
  • 互联网服务提供商信息
  • 大致位置（根据 IP 地址推断，非 GPS）
  • 用户代理和浏览器区域设置
  • 测试日志（不含个人信息）

我们如何使用数据

通过本服务收集的数据将用于：

  • 允许分享测试结果（例如可用于论坛的结果图片）
  • 改进为你提供的服务（例如检测我们一侧的问题）
我们不会向第三方披露个人信息。

你的同意

开始测试即表示你同意本隐私政策的条款。

删除数据

如需删除你的信息，请提供测试 ID 或 IP 地址。这是识别你的数据的唯一方式；没有这些信息， 我们将无法处理你的请求。
